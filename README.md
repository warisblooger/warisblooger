## How a project usually runs

1. **Shape the product** — screens, flow, and what “done” means for the store or the site.
2. **Build it** — Android, iOS, or web, with a UI that feels finished rather than templated.
3. **Ship it** — Play Store, App Store, or a live domain, plus privacy, terms, and support pages.
4. **Stay on it** — fixes, listing updates, and the next version.
